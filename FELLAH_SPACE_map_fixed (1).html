NASA Earth observation · Taroudant

Explore NASA Global Imagery Browse Services (GIBS) map layers. MODIS Terra true-color is a satellite browse image; MODIS Terra NDVI is an 8-day vegetation-index product. NDVI tiles are a regional visualization and are not a field-average measurement.

NASA MODIS true colorImagery date loading…
NASA GIBS imagery service. MODIS NDVI is a satellite-derived vegetation index at coarse regional resolution; it cannot diagnose a specific plant or replace field inspection. Cloud cover, composite period and pixel size affect interpretation.

Understanding NDVI

NDVI is calculated from near-infrared and red reflectance: (NIR − Red) / (NIR + Red). The map layer visualizes the NASA MODIS NDVI product. No numerical field NDVI is calculated by this website.

Security & Privacy

Data confidentiality: collect only information needed for the service and avoid sensitive identity details in this prototype.

User consent: explain what is collected and why, and ask permission before collecting or sharing personal information.

Secure access: a production version should use secure sign-in and server-side permissions for each farmer.

Data protection: use secure storage, backups, retention limits and a way to request correction or deletion.

Prototype transparency: farm profile and task information are stored locally in this browser. Browser local storage is not encrypted. Authentication, cloud synchronization and production-grade access controls are not included. Use fictional sample data for demonstrations. Before real farmers use the service, add HTTPS, a secure backend, authentication, access rules and a reviewed privacy notice.
